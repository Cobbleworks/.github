# Cobbleworks Support

Use the issue tracker in the affected plugin repository for reproducible bugs and the repository's Discussions area for setup questions or feature ideas.

Before requesting help, collect:

- Plugin version
- Minecraft, server implementation, and build number
- Java version
- Relevant dependency versions
- The complete error and surrounding server log lines
- Steps that reproduce the problem on an otherwise minimal server

Never post API keys, database passwords, access tokens, player addresses, or unredacted private configuration.
